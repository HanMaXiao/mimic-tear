# AGENTS.md —— Agent Notes

Agent Note 是 agent 写的 RFC：一份份**持久的提案与决策记录**，留住取舍、替代方案、后果和必须补的验证。规则见 [Agent Note 规则](README.md)。

**每写一份新 note，都要先查一次有没有被取代的旧记录。** 在活跃树里搜同一个决策、同一套机制、同一个被否掉的做法；确属被取代的，按 [归档与删除](README.md#归档与删除) 处理掉，别让两活份互相打架。

**只记代码和文档讲不清楚的东西。** `docs/specs/` 已经写死的约束（运行时库只读、单一写路径、四层架构、21 条路由、12 种 SSE 事件）不要再抄一遍——那些是**事实**，note 记的是**理由**。

被否掉的 note 只有在能挡住一个「看着挺有道理的错误做法」时才留着；否则连同链接一起清掉。
