# AGENTS.md —— 已落地区

这里的 note 描述的是**已经生效**的决策。格式由 [`scripts/verify-agent-notes.mjs`](../../../scripts/verify-agent-notes.mjs) 强制。

必带小节：`## 问题`、`## 决策`、`## 曾考虑的替代方案`、`## 后果`。

## 让 note 跟代码保持一致

**改了路径、名字、默认值、机制，就在同一次改动里把这份 note 改对。** 在原地改事实，不要追加变更历史——note 记的是决策，不是流水账。

例：某个文件挪了位置、改了名、某个键换了名或某个默认值变了，改动过它的那次提交要同时更新对应的 note。

## 这不是改决策的许可证

只更新事实的落地方式。**推翻**决策或它的理由，要写一份新 note 并互相链接；只有满足 [Agent Note 规则里的合并条件](README.md#归档与删除)时，旧 note 才能删。

合并条件：新的那份必须把旧的一份**每一条独有的**理由、替代方案、后果、必须补的验证和已点名的覆盖缺口都保留下来；所有指向旧 note 的链接都要修好；旧 note 一起删。**部分取代不算**——两份都留着，互相链接。

## 什么时候该归档

这份决策已经完整、理由不太可能再指导后续工作、但记录本身还有历史价值时，挪到 [`archived/`](../archived/AGENTS.md)。只描述小改动或纯机械改动的，直接删掉。

归档不是「清理待办」，是**冻结**。封存之后不编辑、不翻译、不重排、不移动、不删除，也不把它当成当前行为的依据。
