# AGENTS.md —— 归档区

`archived/{分类}/` 下的 note 是**冻结的历史快照**，不是当前行为的依据。不编辑、不重排、不翻译、不修链接、不移动、不删除。

归档动作只允许四件事：

1. 把**完整的一份** note 从 `implemented/{分类}/` 移到 `archived/{分类}/`（归档路径里没有 `implemented` 这一层——只有已落地的 note 才有资格进归档）。
2. 在 `Status: implemented` 下面**紧挨着**插入一行 `Archived: YYYY-MM-DD`，日期用归档当天。
3. 修好或删掉指向它的**入链**——活着的正文里该指向当前权威的就指向当前权威，该保留历史引用的才留在归档路径上。
4. 其余一个字都不改。不更新事实、不翻译、不重排、**不修复归档 note 内部的出链**。

归档之后的 note 仍然是合法的入链目标，但它只代表「当时那么定」，不代表「现在还是这样」。要写新决策，就新写一份。

`proposed/` 的 note **不进归档**：不再值得做就诚实地否掉它，走 `rejected/` 的格式。
