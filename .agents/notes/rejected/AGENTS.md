# AGENTS.md —— 已否决区

这里的提案被考虑过，然后被否掉了。文件保持**提案时的样子**冻结：结论写在 `Status:` 行上，不要再改正文。

必带小节：`## 问题`、`## 提案`、`## 曾考虑的替代方案`。

## 留着还是删掉

- **留着**：被否掉的做法本身仍然是一个**看着挺有道理的错误做法**，而这份 note 说清了它为什么输。
- **删掉**：那个想法已经过时、被取代、不再可能、或者再怎么想也不会有人去重蹈覆辙。删的时候把指向它的链接一起修好。

判据是**能不能挡住一次重蹈覆辙**，不是篇幅、不是时间、不是「反正写过了」。

## 不要拿它当禁令

被否掉的理由只对**当时那件事**成立。新的约束、新的事实出现时，结论可能变——那时候写一份新 note，不要把这份改写成相反的结论。
